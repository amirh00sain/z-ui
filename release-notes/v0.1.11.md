# xray-pilot v0.1.11

Final stability pass on node status detection, plus a node bootstrap script.

## Added

- **Node bootstrap script**: `scripts/node-bootstrap.sh` interactively pastes the panel public key, installs Xray, enables BBR and backs up `sshd_config`. The README documents it along with the `curl | bash` usage
- Management pages for users, nodes, profiles and groups keep improving their information hierarchy and now show `#ID` consistently

## Fixed

- False drift detection: remote config reads now use a more reliable transport, and "read failure" is distinguished from a real drift
- Health checks and drift checks now start at offset times, easing SQLite lock contention between scheduled jobs
