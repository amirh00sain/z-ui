# xray-pilot v0.4.1

Usability fixes and small polish after v0.4.0.

## Added

- **The one-click provision button got its own treatment** (green outline and green text), sitting clearly between the solid green "New node" and the neutral grey "Sync pending nodes"
- **The "X nodes" badge in the group list is clickable** and opens that group's edit drawer directly

## Fixed

- **Checking exactly one profile in the profile drawer now shows the full editor**: previously, with a single profile checked the right-hand side collapsed to a lone "Fill template" button — no one-click generate, no settings JSON or port fields. Checking one is now treated as activating that profile; only two or more enter bulk mode
- **The provisioning command no longer relies on sudo passing the environment through**: some distributions default to `env_reset`, which dropped `PANEL_URL` / `INSTALL_TOKEN` and made the script fail. The command no longer uses sudo, and the dialog says explicitly to run it as root (regular users should switch with `sudo su -` first)

## Upgrade

No schema changes and no breaking API changes — overwrite the binary and restart.
