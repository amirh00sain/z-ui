# xray-pilot v0.1.9

Better node details, user editing and Feishu integration.

## Added

- The node list shows the remote `Xray version`, refreshed automatically after a successful SSH test
- The user edit drawer can change the username
- Feishu binding is now admin-led, with email checking, manual identity completion and identity removal
- User and protocol changes mark nodes as "pending sync" more clearly

## Fixed

- The bot pushing the card twice when a user DMs the subscription keyword
- Node status tooltips making the table scroll
