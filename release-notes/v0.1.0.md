# xray-pilot v0.1.0

First public release. A self-hosted Xray management panel for small teams, with the frontend and backend packaged into a single Go binary that deploys straight onto Linux.

## Added

- **Node management**: create / edit / enable-disable / delete, with SSH connectivity tests, single-node and bulk sync, and config previews
- **Protocols and keys**: profile CRUD, plus per-node protocol key generation and maintenance
- **Users and groups**: user and group CRUD, subscription link reset
- **Operations**: subscription link generation, config drift detection, node health checks, activity log
- **System settings**: a subset of system settings can be edited in the panel and persisted

## Artifacts

Prebuilt binaries for Linux amd64 / arm64 and macOS amd64 / arm64, a default service port of `2026`, and a one-line Linux installer script.
