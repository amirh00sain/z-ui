# xray-pilot v0.4.9

Wrapping up the v0.4 series: expired users are removed automatically, traffic details are cleaned up automatically, and instant gRPC apply is now on by default.

## Added

### Expired users are removed from nodes automatically

- Once a user expires, the scheduled job removes them from every node's xray runtime on the drift-check interval, and any live session drops. Previously expiry only blocked new subscription fetches, and already-connected clients could keep using the node until the next full sync
- With instant gRPC apply enabled this happens without restarting xray and without affecting other users; otherwise the nodes are marked drifted and the sync process completes it
- Renewing a user adds them back automatically, with no manual sync needed
- Results are written to the activity log with the actor `system:scheduler:expired_user_sweep`

### Automatic traffic detail cleanup

- Settings → Scheduler gained "Traffic detail retention in days", 90 by default; 0 disables cleanup
- Expired details are removed after each traffic poll. Cumulative totals are untouched, so what the subscription page and clients report does not change

## Changed

- **Instant gRPC apply is now on by default**: on a fresh deployment, user changes no longer restart xray. Existing panels keep their current setting and can change it under Settings → Xray

## Upgrade

- The `users` table gains an `expired_swept_at` column, migrated automatically, existing data untouched
- No breaking changes and no node-side update needed
