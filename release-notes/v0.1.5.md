# xray-pilot v0.1.5

A better subscription entry point, adapted to more client scenarios.

## Added

- **Visual subscription page**: opening `/sub/{token}` in a browser returns an HTML info page with light and dark themes
- **One link, many formats**: the same subscription URL answers with HTML, Base64 or a Clash config depending on how it is accessed
- **Mobile layout**: the subscription page is fully responsive, with QR view / copy / save
- **Quick entry in the panel**: the users page gained "Open subscription page" so you can check a user's subscription at a glance
