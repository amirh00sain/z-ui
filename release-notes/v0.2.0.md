# xray-pilot v0.2.0

Native sing-box profile support in the subscription module.

## Added

- The `?format=singbox` endpoint now returns a complete, ready-to-use sing-box JSON profile (with `log` / `dns` / `inbounds` / `outbounds` / `route` / `experimental.clash_api`), importable directly by Hiddify / Karing / NekoBox / sing-box GUI
- Node outbounds are automatically wrapped into a `selector` (manual switching) plus `urltest` (auto best-pick, latency probe every 3 minutes) pair, matching the "proxy groups" of GUI clients
- Covers four protocols: VLESS+REALITY+Vision, VLESS+WS+TLS, Trojan and Hysteria2
- Responses now send `Content-Disposition: attachment; filename="xray-pilot.json"`, and Clash subscriptions are named `xray-pilot.yaml`

## Upgrade

- No configuration changes needed; the subscription URL shape is unchanged
- V2Ray Base64 (`?format=v2ray`) and Clash YAML (`?format=clash`) output is unchanged
- Baseline sing-box 1.8.0; no remote rule_set dependencies, so the first start never needs to download geosite / geoip
