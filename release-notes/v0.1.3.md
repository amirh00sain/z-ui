# xray-pilot v0.1.3

Console UI rework and interaction consistency.

## Added

- **Dashboard**: a stronger overview of nodes, users, logs and other core information
- **Consistent interactions**: list pages support bulk actions, status toggles, search and filters, and pagination (10/20/50/100 per page, 20 by default for logs)
- **Node SSH parameters**: a node may leave `ssh_key_path` empty and fall back to the system default at runtime
- **Config preview modal**: larger, bidirectionally scrollable, so long JSON is no longer clipped

## Fixed

- Status badge readability in light mode and harshness in dark mode
- Main-pane scrolling stability on long pages

## Upgrade

No breaking changes; the group API gained an optional `active` field. Clear your browser cache after upgrading to pick up the new styles.
