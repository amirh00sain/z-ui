# xray-pilot v0.1.4

Console stability fixes and a better day-to-day operations experience.

## Added

- Node sync, SSH tests and API errors now all surface as toasts
- Protocol keys can be viewed and edited as their real values
- The protocol type is now editable
- Activity logs can be cleaned up by age, with clearer failure reasons

## Fixed

- False positives from `drift_check` firing repeatedly right after a successful node sync
- Group and online-user counts rendering incorrectly on the node detail page
