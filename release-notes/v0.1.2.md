# xray-pilot v0.1.2

Deployment polish and better subscription generation behind reverse proxies.

## Added

- **Deployment diagnostics**: the settings page can now check in one click that the database directory, SSH private key, `known_hosts`, subscription base URL and config file are all readable and writable, with fix suggestions
- **Default paths for systemd**: the SSH private key now defaults to `/etc/xray-pilot/ssh/id_ed25519` and `known_hosts` to `/var/lib/xray-pilot/known_hosts`; the installer creates those directories for you

## Fixed

- Subscription URLs behind a reverse proxy now honour `X-Forwarded-Proto` / `X-Forwarded-Host`, so an Nginx HTTPS proxy produces a correct `https://` subscription address
- Node remarks no longer show `+` instead of spaces

## Upgrade

If you deployed with an earlier installer, check that `subscription.base_url` points at a public HTTPS address, and re-run the installer if needed.
