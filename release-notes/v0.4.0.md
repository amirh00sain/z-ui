# xray-pilot v0.4.0

Node provisioning turned into a product feature, plus a more readable subscription page.

## Added

### One-click node provisioning

The node list gained a "One-click provision" button. Fill in the node metadata and it produces a single curl command. Running it as root on the new node sets up SSH, installs Xray, tunes BBR and registers the node back with the panel — **no hand-typed public key and no second trip to the panel to add the node**.

The token is single-use, bound to the first IP that uses it and expires after 10 minutes by default (you can pick 1 hour or 24 hours in the dialog). The interactive mode of `scripts/node-bootstrap.sh` is unchanged.

### Subscription page improvements

- **Profile badges**: node rows show colour-coded badges for VLESS+Reality / VLESS+WS+TLS / Trojan / Hysteria2, matching the panel
- **Last sync time**: a relative time such as "synced 5 minutes ago", turning amber once a node has not synced for over 24 hours
- **Node remarks**: shown when `Node.Remark` is set, handy for usage notes
- **One-click Clash import**: the Clash backup link gained a `clash://install-config` button so mobile Mihomo / Clash Verge / ClashX open straight into the app

## Upgrade

- The database schema migrates automatically via GORM AutoMigrate; no scripts, no impact on existing data
- No breaking API changes — overwrite the binary and restart

## Notes

- The provisioning command contains a temporary token, so avoid showing it on a shared screen or in a screenshot. The token has a short TTL and is IP-bound, but it is still a credential
- Before using one-click provisioning, confirm `ssh.default_key_path` is set and the matching `.pub` file is readable, otherwise token generation is refused
