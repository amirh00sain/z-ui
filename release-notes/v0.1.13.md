# xray-pilot v0.1.13

Fixes Clash-family clients failing with `invalid yaml` when importing from the backup subscription links, because they were being fed V2Ray Base64 content.

## Added

- **Backup links grouped by client**: generic Base64 (V2rayN / NekoRay / Shadowrocket), Clash family (Mihomo / Clash Verge / ClashX) and Sing-box (sing-box / Hiddify), each with a client example and copy / QR buttons
- Backup links now use an explicit `?format=v2ray|clash|singbox` parameter so a copied link works as-is

## Compatibility

- The primary subscription link `/sub/<token>` behaves the same: it still picks Clash / Sing-box / V2Ray from the `User-Agent`, and the old `?sub=1` alias still works
