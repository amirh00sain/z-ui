# xray-pilot v0.1.8

Feishu bot integration.

## Added

- **Feishu bot configuration**: system-wide Feishu integration, event callbacks, keyword replies and subscription pushes
- **Admin-driven binding**: an admin enables Feishu messaging for a user and sets their email; the identity is bound automatically the first time the user messages the bot
- **Active push**: send a Feishu subscription message to one user or in bulk — handy for launches, node changes and manual notices
- **Feishu message cards**: the primary action is always "Open subscription page", and the subscription URL is plain text to avoid accidental clicks
- **Stable subscription ordering**: the subscription page, the raw subscription and Clash output all sort nodes lexicographically

## Improvements

- The user list shows Feishu status and quick actions
- The settings page supports showing/hiding sensitive fields and a pinned save area on the right
- The right-hand panel of the activity log now follows the scroll
