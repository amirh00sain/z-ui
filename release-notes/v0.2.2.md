# xray-pilot v0.2.2

Scheduled SQLite backups and a backup management screen.

## Added

- A full snapshot every 24 hours (configurable) named `xray-pilot-YYYYMMDD-HHMMSS.db`, written with `VACUUM INTO` so it never blocks the running service
- Expired backups are removed automatically after a configurable retention period (30 days by default)
- A new "Backups" panel in the settings page: list of backups (name / size / created), back up now, download and delete individual files
- Backup directory, interval and retention are all editable in the UI and take effect immediately

## Notes

- **SQLite only**: Postgres users should keep using `pg_dump`
- **Local storage**: backups live on the same host as the service — **strongly consider pulling `data/backup/` off-host on a schedule** with cron, rsync or an object-storage client
- **No automatic restore**: restoring means stop the service → replace `xray-pilot.db` → start again
- **Keep the MasterKey separately**: a backup is only the db file. Reality private keys stay encrypted with AES-GCM, and without the MasterKey they cannot be recovered even from a backup
