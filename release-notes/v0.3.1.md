# xray-pilot v0.3.1

Three frontend fixes.

## Fixed

- **Native `<select>` popups are no longer white-on-white in dark mode**: node filters, pagination and form SelectFields all render correctly
- **The node key drawer list now sizes to its content**: the node list on the left fills the visible area, with no gap that showed a scrollbar before the content ended
- **Long IPs in a node row no longer cover the port or lock state**: the IP truncates automatically so the port number and the 🔒 icon stay visible
- **Backup downloads work again**: backup files download with their auth header instead of being rejected and saved as `download.json`

## Upgrade

Frontend-only fixes, no schema changes — just overwrite the binary.
