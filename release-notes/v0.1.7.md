# xray-pilot v0.1.7

Clearer node lists and consistent optional-field editing in the panel.

## Added

- The node list now shows node name, region and connection address in separate columns
- On the subscription page, the node name and region tag now read in a more natural order

## Fixed

- Optional fields on nodes, users, groups and profiles can now be explicitly cleared and saved (omitting the field keeps the current value; sending an empty value clears it)
