# xray-pilot v0.2.4

Several subscription page UI fixes, plus a client traffic report that v0.2.1 missed.

## Fixed

- **The `Subscription-Userinfo` response header for client subscriptions now carries real cumulative traffic**: it used to be hardcoded to `upload=0; download=0`, so traffic always read as zero in v2rayN, Clash Verge, Hiddify, Shadowrocket and NekoBox. It is now filled from the actual byte counters
- **Cumulative traffic uses a 2×2 grid**: upload / download / total / updated each get their own cell, so the figures line up
- **The "Scan to subscribe" block stays vertically centred when the traffic block on the left grows**
- **The QR modal title is centred**, balancing the close button in the top-right corner
- **Backup-link QR modal titles no longer wrap**: the client example moved into the subtitle
