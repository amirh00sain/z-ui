# xray-pilot v0.2.1

Per-user traffic accounting via the xray-core gRPC StatsService.

## Added

- **Scheduled collection**: every 5 minutes (configurable with `scheduler.traffic_poll_interval`) the panel reaches the remote node's xray gRPC API over an SSH tunnel, pulls and zeroes the counters, then persists them
- **"Total traffic" column in the user list**: shows ↑ / ↓ in human-readable units
- **Dashboard traffic cards**: three new cards — total upload, total download and active users in the last 7 days — refreshing every minute
- **API**: `GET /api/traffic/summary` for the dashboard, and `GET /api/users` now carries `traffic_up_bytes` / `traffic_down_bytes` / `traffic_last_updated_at`

## ⚠️ Required after upgrading

xray does not enable traffic accounting by default. This release adds the `stats` and `policy` sections to the generated config, so you must **trigger "Sync all nodes" once in the panel after upgrading** for the new config to be pushed and reloaded. Until then the dashboard and user traffic fields stay at zero.

## Out of scope for this release

- Quota caps and automatic disabling on overage
- Weekly / monthly aggregates and traffic trend charts
- A per-node traffic detail page
