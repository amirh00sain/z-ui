# xray-pilot v0.2.3

The subscription info page now shows cumulative traffic, so users can check their usage without signing in to the panel.

## Added

- A "Total traffic" block at the bottom of the Account card, with ↑ upload / ↓ download side by side, plus "Total" and "Updated" beneath
- Byte formatting uses binary units (KiB / MiB / GiB) to match the dashboard, and figures use a monospaced font so multiple users are easy to compare

## Fixed

- Users who have never generated traffic now see a "No traffic recorded yet" placeholder instead of a blank card

## Upgrade

No schema changes; just overwrite the binary.
