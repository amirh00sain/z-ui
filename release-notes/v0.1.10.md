# xray-pilot v0.1.10

Better group, node and dashboard management, plus node profile locking.

## Added

- **Node profile locking**: once locked, the backend rejects edits, deletion and key regeneration, which lowers the risk of accidental changes
- **Group list**: descriptions can be hovered, and a tooltip lists the node names in the group
- **Node list layout**: merged the "Users / Xray" column, tidied the group and profile columns, and added an entry point to the node profile overview
- **Dashboard**: clearer hierarchy for recent activity and node health, so key status is visible without scrolling

## Fixed

- Tooltips making the table scroll
