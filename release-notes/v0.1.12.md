# xray-pilot v0.1.12

Many-to-many users and groups, plus subscription page interaction polish.

## Added

- **Users ↔ groups are many-to-many**: one user can belong to several groups, and subscriptions and node configs are merged and de-duplicated automatically
- **User editor**: group selection is now a multi-select dropdown that stays open while you check boxes, with a one-click clear
- **Expiry editing**: pick a time and confirm, with whole-block click-to-open, reset, "today" and clear actions, plus a red hint once the time is in the past

## Fixed

- Drafts generated by one-click generation being lost when the node key drawer was not saved

## Upgrade

- Old `users.group_id` data is migrated into the new `user_groups` relation table on startup; no manual steps needed
